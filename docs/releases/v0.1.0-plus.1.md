# TokenBar Plus v0.1.0-plus.1

发布日期：2026-10-29。首个公开预览版，汇集本分支的中文界面、模型速度与用量统计改进。

## 下载与安装

| 项目 | 内容 |
| --- | --- |
| 下载 | [GitHub Release](https://github.com/WZXsea/TokenBar-Plus/releases/tag/v0.1.0-plus.1) |
| 拖拽安装磁盘 | `TokenBar-Plus-v0.1.0-plus.1-macos-arm64.dmg`，首选 |
| 备用压缩包 | `TokenBar-Plus-v0.1.0-plus.1-macos-arm64.zip` |
| 校验文件 | `SHA256SUMS.txt` |
| 系统与架构 | macOS 14+，Apple Silicon / arm64 |
| 签名 | ad-hoc；Developer ID 签名与 Apple 公证待完成 |
| 应用内版本 | 0.1.0，构建号 1；本分支发行号以 Git 标签为准 |

打开 DMG，将安装窗口左侧的 TokenBar 拖到右侧“应用程序”入口，再从“应用程序”启动 TokenBar，最后推出安装磁盘。已有用户先退出原应用，再替换安装，原有设置与本地记录继续沿用。ZIP 为备用格式，解压后同样将 `TokenBar.app` 拖入“应用程序”。DMG 与应用采用 ad-hoc 签名，Apple 公证待完成；首次打开遇到系统拦截时，在“系统设置 → 隐私与安全性”中核对下载来源后选择“仍要打开”。

![DMG 拖拽安装窗口](https://raw.githubusercontent.com/WZXsea/TokenBar-Plus/main/docs/images/plus-installer.png)

将所选应用包与 `SHA256SUMS.txt` 下载到同一目录后，可在终端校验已下载的文件：

```bash
shasum -a 256 --ignore-missing -c SHA256SUMS.txt
```

当前二进制验收覆盖 Apple Silicon。其他架构可参考[构建说明](../BUILDING.md)从源码构建。

DMG 封装沿用本版应用内容；Git 标签 `v0.1.0-plus.1` 保留首次发布时的源码，后续安装界面与构建脚本见[当前构建说明](https://github.com/WZXsea/TokenBar-Plus/blob/main/docs/BUILDING.md#dmg-拖拽安装界面)。

## 本版内容

1. **中文与紧凑布局**：可选择面板区块并调整顺序；最近会话使用单行布局，限制主面板数量。
2. **模型速率**：独立速度面板、按模型筛选、平滑曲线和坐标轴；异常高值使用范围标记，保留原始采样值。
3. **菜单栏轮播**：数字停留 3 秒，横向切换约 1.5 秒；颜色复用面板模型配色。悬停暂停，左右滚动手动切换，空闲保留最近速率。
4. **刷新响应**：提供 1 秒选项，会话文件变化触发本地更新；后台静止时采用较低刷新频率。
5. **用量与额度**：周、月、年记录视图；分日额度颜色；重置以来的 Token、费用、会话和轮数；可展开额外重置记录。
6. **套餐与计费**：套餐类型标识、PRO／PLUS 样式，以及按模型和服务档位编辑的本地价格估算。
7. **ZCode 适配**：读取本机数据库和历史日志，支持其中接入的第三方模型及自定义价格。ZCode 响应速率按请求总时长计算，包含首 Token 等待时间。

## 统计与来源

本次发布前重新运行 Swift 37 项、Rust 19 项测试，并核验压缩包解压后的应用签名、可执行文件架构与 SHA-256。

费用为本地估算，实际计费以服务商账单为准。速度由客户端日志中可取得的 Token 和请求时间计算；采样与刷新受到日志写入节奏及扫描耗时影响。分日额度反映本工具已观测的增量，详情见[统计口径](../../README.md#统计口径)。
